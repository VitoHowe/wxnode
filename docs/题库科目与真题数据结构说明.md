# 题库科目与真题数据结构说明

## 目的
建立“科目 -> 题库集 -> 章节/题目”的层级模型，支持真题独立存储与统计，并为专项/随机训练提供可扩展的数据基础。

## ER 关系概览
- subjects 1..n question_banks
- subjects 1..n subject_chapters
- subject_chapters 1..n question_chapters
- question_banks 1..n question_chapters
- question_chapters 1..n questions
- subjects 1..n real_exam_papers
- real_exam_papers 1..n real_exam_questions
- real_exam_papers 1..n real_exam_attempts
- real_exam_attempts 1..n real_exam_wrong_questions
- subjects/subject_chapters 1..n user_special_progress

## 表结构要点
- subjects：科目表（name/code/status/sort_order）
- question_banks：新增 subject_id 关联科目
- subject_chapters：科目级章节基准（chapter_name 为基准名，display_name 可改名）
- question_chapters：新增 subject_chapter_id 映射到科目章节
- questions：新增 random_key 供随机抽题采样
- real_exam_papers / real_exam_questions：真题试卷与题目
- real_exam_attempts / real_exam_wrong_questions：真题统计与错题（不保存进度）
- user_special_progress：专项训练进度（展示百分比）

## 迁移清单
1) 应用启动自动迁移：`wxnode/src/config/database.ts`
2) 手动 SQL 脚本：`wxnode/migrations/add_subjects_real_exams_and_special.sql`

## 旧数据回填策略（概要）
1) 默认科目：为历史题库创建默认科目（例如“高级项目管理”），将相关 question_banks.subject_id 回填。
2) gemini 章节基准：以 gemini 题库章节列表生成 subject_chapters，display_name 初始与 chapter_name 一致。
3) 章节映射：按 subject_id + chapter_name 匹配，将 question_chapters.subject_chapter_id 回填。
4) 异常处理：无法匹配的章节保留空值，交由后台配置修正。
5) 随机键：批量回填 questions.random_key（可在脚本中用随机函数或规则分布生成）。

## 说明
- 真题练习不保存进度，只保存准确率与错题记录。
- 专项训练展示百分比；随机训练不展示百分比。
